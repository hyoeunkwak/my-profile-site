SmartThings Compatible Devices

Client / Platform
Samsung Electronics / Samsung.com
Period
Aug – Sep 2024

A UX/UI project that connects SmartThings compatible-device information, previously offered on a separate ST mall, to Samsung.com's design system, improving brand consistency and information discovery.

별도 ST몰에서 제공되던 SmartThings 호환 기기 정보를 Samsung.com의 디자인 체계와 연결하여 브랜드 일관성과 정보 탐색 경험을 개선한 UX/UI 프로젝트.

Role

UX/UI Designer · UI structure & content design

UX/UI 디자이너 · UI 구조 및 콘텐츠 디자인

Contribution

Within the constraint of keeping the existing ST mall development structure, applied the Samsung.com design system to organize the information hierarchy, filters, thumbnails, CTAs and other key UI elements.

기존 ST몰의 개발 구조를 유지해야 하는 제약 속에서 Samsung.com 디자인 시스템을 적용해 정보 위계, 필터, 썸네일, CTA 등 주요 UI 요소를 정비.

More Info
Constraints

Samsung.com global design system and UI component standards · keeping the ST mall's existing development structure

Samsung.com 글로벌 디자인 시스템 및 UI 컴포넌트 기준 · ST몰의 기존 개발 구조 유지

Deliverables

New Compatible Devices page UI · Information discovery and filter UI · Brand, category and product list components · Key UI component designs · Desktop and mobile design outputs

Compatible Devices 신규 페이지 UI · 정보 탐색 및 필터 UI · 브랜드·카테고리·제품 리스트 컴포넌트 · 주요 UI 컴포넌트 디자인 · 데스크톱 및 모바일 디자인 결과물

Key decisions
  • Aligned the independent ST mall UI with Samsung.com design standards.기존 ST몰의 독립적인 UI를 Samsung.com 디자인 기준에 맞춰 정비.
  • Realigned thumbnail ratio, text hierarchy, filter composition and CTA style.썸네일 비율, 텍스트 위계, 필터 구성, CTA 스타일 등 핵심 UI 요소를 재정렬.
  • Defined an improvement scope that could actually be applied within the existing structure.기존 개발 구조를 유지해야 하는 제약을 고려해 실제 적용 가능한 개선 범위를 정의.
Takeaway

Rather than building a new system, I used the existing design system to arrive at an improvement that could actually be implemented.

새로운 시스템을 구축하기보다 기존 디자인 시스템을 활용해 실제 구현 가능한 개선안을 도출했다.
